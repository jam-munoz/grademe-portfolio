# dangling\_repair

Repair a label builder that reads heap memory it has already released

```c
char *build_label(const char *name, int id)
```

**Difficulty:** 3/5
**Allowed functions:** malloc, free

Solved as level 3 of the c-memory-checkpoint challenge.
Validated 2 times. Earlier versions are in this file's git history.
