# str\_join

Allocate exactly once to join n strings with a separator byte and hand ownership to the caller

```c
char *str_join(char **parts, size_t n, char sep)
```

**Difficulty:** 3/5
**Allowed functions:** malloc

Solved as level 1 of the c-memory-checkpoint challenge.
Validated 2 times. Earlier versions are in this file's git history.
